🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: Chatbot button not visible
─────────────────────────────────────
SOLUTION:
1. Clear browser cache (Ctrl + Shift + R)
2. Check if chatbot_partial.html exists
3. Verify JavaScript is enabled in browser
4. Check browser console for errors (F12)

PROBLEM: History page shows "No Assessments Yet"
────────────────────────────────────────────────
SOLUTION:
1. Ensure you're logged in (check navbar shows username)
2. Complete at least one assessment at /predict
3. Check database: sqlite3 db\predictions.sqlite
   > SELECT * FROM predictions WHERE user_id = <your_id>;

PROBLEM: Animations not working
───────────────────────────────
SOLUTION:
1. Use modern browser (Chrome, Firefox, Edge)
2. Check if hardware acceleration is enabled
3. Disable browser extensions that block animations
4. Verify styles.css is loading (Network tab in DevTools)

PROBLEM: Port 5000 already in use
─────────────────────────────────
SOLUTION:
1. Find process: netstat -ano | findstr :5000
2. Kill process: taskkill /PID <pid> /F
3. Or use different port: flask run --port=5001

PROBLEM: Database error "no such table"
───────────────────────────────────────
SOLUTION:
1. Delete db\predictions.sqlite
2. Restart Flask server (it will recreate tables)
3. Or run: python -c "from api.app import init_db; init_db()"
