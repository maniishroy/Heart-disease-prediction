Project Overview

HeartCheck DL is a state-of-the-art deep learning application that leverages TensorFlow/Keras neural networks to predict heart disease risk based on comprehensive clinical and lifestyle factors. The system analyzes 13 key indicators including age, blood pressure, cholesterol levels, ECG results, and medical history to provide personalized, evidence-based risk assessments.

Built with Flask, TensorFlow, and modern web technologies, this platform demonstrates the practical application of machine learning in healthcare risk assessment while maintaining complete transparency about its limitations and appropriate use cases.

Model Architecture

🧠

Neural Network

Multi-Layer Perceptron (MLP) with deep learning architecture

  • Input: 13 clinical features
  • Hidden layers: 128, 64, 32 neurons
  • Activation: ReLU + Sigmoid
⚙️

Optimization

Advanced training techniques for optimal performance

  • Adam optimizer
  • Batch normalization
  • 30% dropout regularization
📊

Training

Smart callbacks and monitoring for best results

  • Early stopping
  • Model checkpointing
  • Learning rate reduction
